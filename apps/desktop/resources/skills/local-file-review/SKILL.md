# 本地文件检查

1. 确认会话工作目录。尚未授权时使用 set_working_directory 让用户确认。
2. 先用 list_directory 确认文件位置，再用 search_text 定位相关内容。
3. 用 read_file 阅读命中位置及上下文，结论引用实际文件和行号。
4. 对相互独立的只读检查可以使用 delegate_tasks；遵守该工具当前的委派限制。
5. 用户要求分析或审查时只报告发现；只有用户要求修复时，才通过现有文件修改审批进行写入。
6. 区分代码证据、已执行的验证和尚未验证的猜测，避免把搜索结果当成实际运行结果。
