# Documentation（文档）

这是项目未来文档入口。

后续文档预计包含以下主题：

```text
English term                    中文术语        介绍
architecture                    架构            记录系统边界、模块关系和关键设计。
MVP specification               MVP 规格        定义当前最小可运行阶段的目标和验收标准。
subsystem contracts             子系统契约      记录模块之间的接口、输入输出和责任边界。
architecture decisions / notes  架构决策与说明  记录重要决策及其背景、取舍和影响。
testing                         测试            记录测试策略、验证方式和质量要求。
development guides              开发指南        记录本地开发、验证和协作流程。
```

### [mvp.md](mvp.md)

MVP 规格

定义当前最小可运行目标、Echo 场景、范围、非目标和验收条件。

### [architecture.md](architecture.md)

架构规格

定义 Agent Runtime MVP 的核心概念、生命周期、依赖方向和架构不变量。

### [engineering.md](./engineering.md)

工程基线

定义当前项目已经生效的工程技术基线、包布局和依赖规则。
