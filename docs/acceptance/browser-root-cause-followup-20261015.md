# 浏览器失败补充调查与隔离入口修正

日期：2026-10-15。分支为 `codex/final-browser-stabilization`，调查基线为 `23f46d085ad040a99745e85b0eb2b669e8c66ba5`。本次继续回答失败原因，保留[完整重跑报告](browser-full-rerun-20261015.md)的 74 通过、18 跳过、2 失败及退出码 1，不将后续单项成功改写为整套成功。

## 隔离事故：原因确认，历史影响无法完整追溯

原因已经确认：准备端清理环境变量留下空字符串；Vision、Whisper 的 `??` 接受空字符串，两个安装配置专项也只按 `undefined` 判断缺少条件。空 `--user-data-dir=` 最终使测试进入默认用户配置。这是验收准备与测试入口的隔离失误，现有证据不支持归为产品业务缺陷。

仅在 `desktop-vision.pw.ts`、`desktop-whisper.pw.ts` 各一处和 `desktop-probe.pw.ts` 两处增加空字符串拒绝，共四行，位于目录操作及 Electron 启动前。正常路径和变量缺失时的原有行为保持不变；错误配置直接失败，不增加跳过或自动切换目录。

原配置、插件、会话及模型资产的完整前后差异缺少事前快照，继续重跑不能补出历史基线。已确认操作及未知范围仍见原事故报告。本次补充调查没有直接查询默认用户数据库、提取或输出解密密钥，也没有自动恢复或删除默认数据；不声称事故对用户数据无影响。

## Whisper：同一用例的冷资源获取耗尽预算

原完整重跑中，模型安装等待 1448345.609 毫秒成功，随后 FFmpeg 安装 182386.754 毫秒成功，合计占原 1800000 毫秒总预算约 90.6%。长音频等待另耗 67474.138 毫秒，后续生命周期继续执行到末次重启时仅余约 0.4 秒。直接失败原因是总预算耗尽，不是模型下载断言失败、应用关闭挂死或已证明的启动挂死。

源码下载器只有一次应用层 `net.fetch` 和流写入，没有自动重试。安装等待覆盖网络、落盘、校验和结果提示；原记录缺少首字节、逐时进度与连接数据，不能认定具体源站限速或下载器缺陷。因此没有修改下载器、超时、重试或现有断言，也未以预置模型跳过冷下载来制造通过。

本次显式采集 Electron 上下文执行轨迹，含 186 个页面快照及 282 帧录屏，证据位于 `logs/browser-stabilization/probe-root-cause-20261015-152958/`。诊断将原安装与保存的联合调用拆开，并增加观察和截图，改变了执行时序；监听挂接前及后续实例覆盖有限，不能用本次成功反推原失败原因。临时诊断代码已经按原文件字节恢复并核对摘要，最终只保留两个安装配置入口的空路径拒绝检查。
