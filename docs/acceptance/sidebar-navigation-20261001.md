# 项目与会话侧栏验收

日期：2026-10-01。分支：`feature/settings-navigation`。根据用户“我们也这么做”的要求，实现前轮研究建议的侧栏管理范围；参考截图位于 `logs/codex-sidebar-reference-20261001/`，现行视觉规则只以 `docs/desktop-ui.md` 为准。

## 范围与设计

```text
Goal           目标        可用的项目与最近会话导航，包含置顶、归档恢复和自动保存。
Problem        问题        平铺列表缺少项目入口、折叠和保留历史的整理方式。
Impact scope   影响范围    共享侧栏与输入区、展示快照、桌面目录接口、网页夹具及相关验证。
Non-goals      非目标      通知、多窗口、未读、聊天分叉、拖动排序、多源目录及标记选择器。
```

沿用现有会话快照与 SQLite 存储，不创建 package、数据库表或依赖。项目与工作目录分开：添加项目只登记目录；项目内新会话明确使用目录，已有聊天移动或项目移除只调整归属。模型事件与智能体核心没有本轮变更。

## 已完成

- 项目与最近分区、单项目和分区折叠、分项目与合并显示、折叠后的任务状态标记。
- 系统文件夹选择添加项目；项目内新会话、项目置顶、改名称、打开目录、批量归档和带确认移除。
- 会话悬停置顶与归档快捷按钮、右键与省略号共用菜单、重命名、移动归属、归档恢复和原有删除。
- 最近会话置顶优先，其余按真实创建及任务更新时间排序，访问和草稿不改时间。
- 归档保留草稿、历史和产物；当前聊天归档后转入未归档聊天，全部归档后由宿主新建。归档历史可查看，恢复后继续原会话。
- 项目、归属、置顶、归档、分组和折叠自动存储并恢复；旧快照继续读取，没有新增数据库配置。
