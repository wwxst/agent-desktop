# 设置自动保存验收

日期：2026-10-01。分支：`feature/settings-navigation`。根据用户要求移除手动保存按钮及底部保存栏；现行视觉规则见 `docs/desktop-ui.md`，本记录替代前次分类页面验收中的手动保存交互。

## 结果

- 主题点选后自动保存并生效；普通文本和密钥在失焦、回车或设置输入框内按 Escape 时提交。
- 每次只提交改动字段；空普通字段清除覆盖，空密钥输入恢复掩码，清除密钥仍使用明确动作。
- 连续编辑顺序保存，宿主响应不会覆盖新的输入；失败显示错误并保留输入，修改后再次失焦可以保存。
- 输入法组词期间的回车不触发保存；执行任务期间设置仍禁止修改。
- 顶部显示保存状态或错误，返回入口固定可达；桌面、800px 和 400px 实际截图无横向溢出。
- 真实生产桌面中，模型名称输入后直接 Escape 返回，再选择深色，宿主读取与重启恢复均正确；全程不点击保存按钮。
